# OCaml keyword names

Valid Haxe methods and locals named `effect` must compile on OCaml versions that reserve this word.
The fixture also uses `effect_` to detect collisions after name escaping.
Both methods and both local values must retain their distinct results.

Run `haxe test/m14_ocaml_keyword_names_integration_test.hxml` from the repository root.
The test compares an authored expectation with upstream Haxe and a native executable generated by current hxhx source.
Failures retain generated files under `.tmp/ocaml_keyword_names_*`.

This focused check does not prove a standalone hxhx build or full Haxe compatibility.
