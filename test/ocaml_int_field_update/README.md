# Native OCaml Int field updates

An Int field increment must update the object and return the correct value.
Postfix updates return the old value; prefix updates return the new value.
The fixture also checks decrement, receiver evaluation counts, a Void method, and 32-bit Int wraparound.

Run `npm run test:m14:ocaml-int-field-update` from the repository root.
The test compares an authored expectation with upstream Haxe and native OCaml output generated by current hxhx source.
Failures retain generated files and actual output under `.tmp/ocaml_int_field_update_*`.

The OCaml lowering uses exact Int instance-field facts and explicit typed temporaries.
Properties, static fields, nullable fields, and abstract operators retain their existing handling.
This fixture does not establish their support, Float semantics, a standalone compiler build, or full Haxe compatibility.
