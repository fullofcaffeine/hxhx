# Expected red: Array resize and splice

## Scenario

Given a final typed call to the root Haxe `Array<T>`, the call plan must name
`resize` or `splice` before OCaml syntax generation can use the corresponding
private runtime function.

## Command

`npm run test:reflaxe-ocaml:call-plan`

## Expected failure

The focused fixture failed at `CallPlanFixture.hx:1671` because
`OcamlStandardArrayOperation` had no `Resize` field. This was the intended
failure: the closed compiler-owned operation model did not yet admit either
new operation. The test failed before generated OCaml or runtime behavior
could hide the missing plan.

## Independent oracle

The behavior oracle is the installed Haxe 4.3.7 compiler running the shared
`ArrayMain` source. The same source is then compiled to OCaml, built with Dune,
and executed. The expected behavior is therefore not generated by the
`reflaxe.ocaml` implementation under test.
