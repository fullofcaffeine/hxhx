## User-visible outcome

Compiler-generated OCaml files cannot contain an internal `Hx...` reference
that bypasses the same planned-use authority applied to structured target
syntax.

## Scope

Introduce a checked generated-text builder with literal chunks and typed
runtime-use placeholders. Migrate one representative generated module first,
then create bounded follow-up children from the frozen inventory. This task
does not change user-authored `__ocaml__` policy.
